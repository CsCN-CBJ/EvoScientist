# 整体架构

EvoScientist 是一个面向自动化科学发现的多 Agent AI 系统，编排 6 个专业化子 Agent 执行完整科研生命周期。

## 模块划分

| 模块 | 目录 | 职责 |
|------|------|------|
| Agent 核心 | `EvoScientist.py` | Agent 图构建、延迟初始化、子 Agent 加载 |
| 子 Agent | `subagent.yaml` | 6 个专业化 Agent 的声明式定义 |
| 提示词 | `prompts.py` | 系统提示词（实验工作流、委派策略、研究指令） |
| 后端 | `backends.py` | 沙盒执行、文件操作、技能目录合并 |
| 中间件 | `middleware/` | 记忆、工具选择、上下文编辑、错误处理等 |
| 通道 | `channels/` | 10 个消息平台集成 |
| LLM | `llm/` | 多 Provider 模型配置和路由 |
| MCP | `mcp/` | Model Context Protocol 工具集成 |
| CLI/TUI | `cli/` | 命令行和终端用户界面 |
| 流式输出 | `stream/` | 事件处理和 Rich 渲染 |
| 配置 | `config/` | 配置加载/保存/合并 |
| 会话 | `sessions.py` | SQLite 会话持久化 |
| 技能 | `skills/` | 内置技能和技能管理器 |
| 工具 | `tools/` | think_tool、tavily_search、skill_manager |

## 数据流

1. **用户输入** → CLI/TUI 或消息通道接收
2. **InboundMiddleware** → 去重、白名单、配对、群组历史、@提及过滤
3. **Agent 核心处理** → 主 Agent 调度子 Agent 或直接使用工具
4. **中间件链** → 上下文编辑 → 工具选择 → 记忆注入/提取 → 错误处理
5. **后端执行** → 沙盒内 shell 命令、文件读写
6. **流式输出** → 事件发射器 → Rich 渲染到 CLI/通道
7. **会话持久化** → SQLite checkpointer 保存对话状态

## 技术栈

- **Agent 框架**: DeepAgents（LangChain 团队出品，基于 LangGraph）
- **LLM 接入**: LangChain `init_chat_model`，支持 15+ provider
- **会话管理**: LangGraph `AsyncSqliteSaver`
- **CLI 框架**: Typer + Rich + Textual（TUI）
- **消息通道**: 各平台 SDK + aiohttp/websocket
- **外部工具**: MCP 协议（langchain-mcp-adapters）
- **语音转文字**: faster-whisper
- **包管理**: uv + pyproject.toml
